For compatible MOTU AVB devices, the API URL is the URL of your MOTU device web interface, adding a "/datastore" at the end.

Targets

One endpoint=value pair per line. Pressing the key PATCHes every pair. The key shows its ARMED state only while the live datastore matches all pairs, so the indicator always reflects the real routing - it cannot go stale.

Example (stereo pair):
ext/obank/0/ch/14/src=0:2
ext/obank/0/ch/15/src=0:3

An empty value after the "=" is sent as an empty string ("").
